### 🎓 Featured project: [UniSphere](https://github.com/YusufRashi/unisphere-portal)

A university information system with separate workspaces for students, lecturers, the registrar, and finance.

- Course registration with prerequisite, credit-load, and timetable-clash checks
- Marks entry, GPA calculation, and downloadable PDF transcripts
- Fee accounts with a payment ledger and finance reports
- Live notifications, an audit log, and light and dark themes

**Spring Boot 4 · Java 25 · PostgreSQL · React 19 · TypeScript · Tailwind CSS · Docker · GitHub Actions**
